# get basic data to calculate performance metrics

get basic data to calculate performance metrics

## Usage

``` r
get_performance_metrics(
  dir = getwd(),
  use_SSMSE_summary_all = TRUE,
  quantities = c("catch", "SpawnBio")
)
```

## Arguments

- dir:

  Path to the directory containing the scenarios, either relative or
  absolute. Defaults to the working directory.

- use_SSMSE_summary_all:

  If it exists, should the summmary files generated by SSMSE_summary_all
  be used? Defaults to TRUE.

- quantities:

  Quantites from the operating model to add
