# function that creates a combined column to the list_item of interest

function that creates a combined column to the list_item of interest

## Usage

``` r
combine_cols(dat_list, list_item, colnames)
```

## Arguments

- dat_list:

  An SS3 data file as a list read in using r4ss

- list_item:

  List item in dat_list to extract and return a modified version of this
  value

- colnames:

  Column names in list_item
