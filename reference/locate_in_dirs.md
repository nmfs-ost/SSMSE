# Locate the OM model files

Locate the OM model files

## Usage

``` r
locate_in_dirs(OM_name = NULL, OM_in_dir = NULL)
```

## Arguments

- OM_name:

  Name of the operating model (OM).

- OM_in_dir:

  Relative or absolute path to the operating model, if using a model
  outside of the SSMSE package. Should be a string.

## Value

A list with a component, OM_in_dir, which contains the model location
