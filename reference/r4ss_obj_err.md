# Error if object is not an r4ss object

Error if object is not an r4ss object

## Usage

``` r
r4ss_obj_err(obj_name = "object ", type = "list")
```

## Arguments

- obj_name:

  Object name that is not an r4ss object to print in the error

- type:

  Type that obj_name was expected to be, but is not,
